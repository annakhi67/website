# Portfolio site (publish this folder)

- `index.html`: the portfolio home page
- `work/<project>/case.html`: five case studies, each with its own prototype and assets
- `assets/`: photo, resume PDF, cover images and videos

To publish: drag the whole `site` folder into netlify.com/drop, or push it to a GitHub repository and turn on GitHub Pages.
Before publishing, check: "Berlin" and the dates in the About section, and that you own or may show the Social Survey App video.
